
# Height and Weight Data Analysis

This project focuses on data processing, analysis, and visualization using Python, NumPy, Pandas, and Matplotlib.

## Overview

The project explores numerical datasets and analyzes height and weight measurements through data cleaning, statistical calculations, and visualization.

## Features

- Processed numerical data using NumPy
- Cleaned and analyzed height and weight datasets
- Converted height measurements from inches to centimeters
- Converted weight measurements from pounds to kilograms
- Identified and handled data anomalies
- Visualized distributions using histograms
- Analyzed grouped means and numerical patterns

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib

## How to Run

1. Make sure the following files are in the same folder:
   - `height_weight_analysis.py`
   - `data_q1.csv`
   - `height_and_weight.csv`

2. Install the required libraries:

   ```bash
   pip install numpy pandas matplotlib
   ```

3. Run the Python script:

   ```bash
   python height_weight_analysis.py
   ```

## Output

The program generates visualizations and analysis results, including:

- Histograms of grouped means
- Height distribution in centimeters
- Weight distribution in kilograms
